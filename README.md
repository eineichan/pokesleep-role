# 📋 ポケスリ役割チェック

ポケスリのBOXから「いる／いらん」を役割ごとにサクサク仕分ける、軽量な1ページWebアプリです。仲間内でそのまま共有できます。

- 🍎 食材べつ（全20種）
- 🍒 島別きのみ（全6島）
- ✨ スキル別（全6役）

にとよん（個体値計算機）で出た1日の数字を入れると、合格ライン・エース級（理想）ラインを自動で判定します。

| タブ | 入れる数字 | ラインの目安 |
| --- | --- | --- |
| 🍎 食材 | 1日の個数 | 上位料理3食ぶん（2食ラインで合格） |
| 🍒 きのみ | 1日のきのみエナジー（好物きのみ×2込み） | 合格＝きのみS Lv50級／エース級＝Lv60級 |
| ✨ スキル | 1日のスキル発動回数 | 合格＝無補正〜スキル確率↑／理想＝厳選を詰めた個体 |

- スクショからの数字読み取り（カンマ付きの大きい数字もOK）
- 1タップの状態管理（未確保 → 厳選中 → 確保済み）・絞り込み・メモ・条件チップ
- localStorage自動保存＋JSONバックアップ
- ラインを超えるとハート＆紙吹雪（音は右上の🔊でON。初期はミュート）

### 数字の出どころ

- 食材：ゲームエイト 料理レシピ一覧／豆腐メンタル 食材別ランキング
- きのみ：ポケらく 島別きのみエナジーランキング（2026-11-16更新）
- スキル：ポケモンスリープ攻略Wiki スキル発動回数期待値一覧／ポケスリ総合資料サイト／ゲームエイト／ポケらく

目標値は各カードのメモ欄から自分で変えられます。
